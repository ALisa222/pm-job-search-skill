# pm-job-search — скилл Claude Code для поиска работы продактом

Ищет работу продакт-менеджеру по шагам:

1. **Интервью.** Спрашивает про грейд, опыт, стадию и уровень компании, домены, модель бизнеса, формат, рынок, вилку, оформление, стоп-факторы и способ выхода на компании.
2. **Анализ рынка — при каждом запуске.** Считает вакансии на бордах, смотрит вилки, кто нанимает, увольнения и раунды. Показывает динамику с прошлого замера и заново пишет «Главный вывод рынка».
3. **Открытые вакансии.** Каждую ссылку открывает, в бриф попадает дата публикации.
4. **Целевые компании без вакансии.** По тирам, с «почему тебе», ЛПР и публичными каналами захода.
5. **Бриф-досье в HTML.** Фильтры по тирам и доменам, шаблон письма фаундеру, флаги достоверности.
6. **Трекер откликов** с напоминаниями.

Источники в комплекте — для российского рынка. Для других рынков скилл ищет аналоги сам.

## Установка

```bash
git clone https://github.com/ALisa222/pm-job-search-skill ~/.claude/skills/pm-job-search
```

Перезапусти Claude Code — появится команда `/pm-job-search`.

Нужны: Claude Code, `python3` (собирает бриф), доступ к веб-поиску (WebSearch / WebFetch).

## Как пользоваться

Открой Claude Code в папке, где будут лежать результаты, и запусти:

| Команда | Что делает |
|---|---|
| `/pm-job-search` | Первый раз — интервью и полный цикл. Дальше — свежий срез рынка и обновление брифа. |
| `/pm-job-search обнови` | Срез рынка, новые вакансии, проверка, что старые не закрылись. |
| `/pm-job-search трекер` | Кому пора написать или напомнить сегодня. |
| `/pm-job-search письмо <компания>` | Готовое сообщение фаундеру или ЛПР одной компании. |
| `/pm-job-search профиль` | Поменять ответы интервью. |

Можно и словами: «найди вакансии продакта», «что сейчас на рынке продактов», «обнови вакансии».

Результаты лежат в `JOB-SEARCH/` в текущей папке:

- `PROFILE.md` — ответы интервью;
- `MARKET.md` — журнал срезов рынка;
- `brief.html` — бриф, открывается в браузере;
- `TRACKER.md` — воронка откликов.

В папку скилла твои данные не попадают.

## Принципы

- Ничего не выдумывает: у каждой вакансии, имени и цифры есть источник и дата.
- Контакты — только публичные профессиональные: карьерные страницы, формы, почта с сайта, публичные профили. Почты по шаблону не угадывает.
- Компромиссы показывает честно: компания с лучшим фитом, но не той стадии, идёт в Тир 3 с пометкой.
- Письма не рассылает — готовит одно точное сообщение, отправляешь его ты.

## Что внутри

- `SKILL.md` — сам скилл: режимы, правила, шаги.
- `reference/interview.md` — вопросы интервью и шаблон профиля.
- `reference/research.md` — как делать анализ рынка, искать вакансии и компании, тиры, письмо.
- `reference/sources-ru.md` — борды, Telegram-каналы, базы стартапов, данные о зарплатах (ссылки проверены 18.10.2026).
- `templates/brief.html` — шаблон брифа; `templates/brief-data.example.json` — формат данных (вымышленный пример).
- `templates/tracker.md` — шаблон трекера.
- `scripts/build_brief.py` — собирает бриф из JSON и проверяет данные.
