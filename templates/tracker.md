# Трекер поиска — обновлён: YYYY-MM-DD

Статусы: цель → изучено → контакт найден → написал(а) → ответили →
интервью → оффер / отказ / пауза

Правила:
- После «написал(а)» — следующий шаг через 5–7 рабочих дней:
  одно напоминание. Нет ответа после него — «пауза».
- Даты — ГГГГ-ММ-ДД, чтобы сортировались.
- Закрылась вакансия или компания пропала с радаров — отметить
  в заметках, строку не удалять.
